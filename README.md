# automacao-python-pandas
Script em Python para automação de dados utilizando PyAutoGUI e Pandas

Python, Bibliotecas pandas e pyautogui

O código de automação pode ser utilizado para facilitar o manuseio de bases de dados, automatizando seu registro . Ele também pode ser utilizado para automzatizar tarefas básicaas, como por exemplo, abir um site o aplicativo.
